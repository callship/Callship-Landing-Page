# Callship

**The Low-Pressure, ADHD-Friendly Friendship Companion**

Callship helps neurodivergent thinkers, introverts, and overthinkers stay connected with loved ones without guilt, overwhelm, or corporate CRM complexity.

---

## Key Features

- **1-Card Daily Spotlight**: Surfaces one friend at a time to eliminate choice paralysis and decision fatigue.
- **Relational Object Permanence**: Visual cosmic orbits (Inner Core, Close Circle, Outer Orbit, Distant Constellation) keep friends top of mind without stressful checklists.
- **1-Tap Shame-Free Reset**: Erases overdue guilt counters instantly, offers self-compassionate outreach scripts, and grants +20 XP for choosing self-kindness.
- **2-Minute Micro-Sprints**: Structured phone sprint protocol featuring an 8-second breathing pacer, clear upfront boundary scripts, and guaranteed graceful exit lines.
- **100 Levels of Gamification**: Rewards every small effort of connection and self-forgiveness.
- **100% Free & Private**: No paywalls, no advertisements, zero tracking, and 100% local device storage. Voluntary coffee tip jar support for the indie developer.

---

## Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (Clean, high-contrast light theme with precision geometry)
- **Icons**: Lucide React
- **Micro-Interactions**: Canvas Confetti
